Requirements

环境要求

  • 必须：Edge 浏览器（Windows 自带）
  • 系统：Windows 10 / 11，预留 20 MB 空间
  • 权限：需以管理员身份运行（它要启动浏览器调试端口并执行 PowerShell）
Origin

起源

先说网上的项目

  • 正经的 Agent（如各大厂商的 Agent Harness）—— 功能强大，但都要 API-Key、要花钱买 token。
  • 网页反代类 —— 通过反代白嫖 token，功能也不弱，但封号概率大。
  • 本项目核心是 CDP 自动化操控网页，封号概率更小（但不是 0，详见下方声明）。

再看这个项目

  • 免费的文心网页版足够日常用，小项目没必要买 token（而且它有时会“吃白饭”，思考陷入死循环白烧钱）。
  • 但文心网页版无法直接编辑电脑文件：最多生成代码，还得复制粘贴，不能真正“操控”电脑。
  • 于是思路很简单：直接生成 PowerShell 代码 → 执行 → 把结果扔回去。
  • 本项目由此而来：让百度文心网页版编辑电脑文件、看电脑屏幕、控制键鼠、编辑 Excel / Word……还会更多。
Quick Start

快速使用

  • 下载：EAgent-文心.exe（本仓库 dist/ 目录）
  • 右键 → 以管理员身份运行（不要直接双击）
  • 点击 选择工作目录，选择一个目录
  • 程序会自动打开 Edge 并进入文心页面；文心免登录即可基础对话，如需完整功能请登录百度账号
  • 点击 开始新对话，等待 AI 分析提示词
  • 用 EAgent 发消息，而不是在网页里发 —— 网页只负责展示
Under the Hood

实现原理 —— 自动化脚本

  • EAgent 不是反代、没有第三方中转、不逆向文心接口。
  • 核心原理：通过 CDP 自动化模拟真实用户操作。和反代一样，这类操作可能违反 《文心用户协议》， 请自行评估风险。
用 PowerShell 连接 Chrome/Edge 调试端口，
通过 CDP WebSocket 在文心页面里执行 JavaScript，
模拟输入、上传文件、点击发送，并轮询判断助手回复是否完成、返回助手回复信息。
